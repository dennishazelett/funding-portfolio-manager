# Funding Portfolio Manager

Source repository for the ChatGPT `funding-portfolio-manager` skill.

## Structure

- `SKILL.md` — skill entrypoint and workflow instructions
- `agents/openai.yaml` — ChatGPT UI metadata
- `references/portfolio-model.md` — current-state portfolio structure and conventions
- `references/decision-rules.md` — opportunity triage, overlap, cadence, and collaborator decision rules

## Maintenance workflow

Edit the source files in this repository, validate the skill, then package it for upload as `skill.zip` using the current OpenAI skill-creator tooling.

Keep repository history here; keep the portfolio itself current-state rather than using it as an activity archive.
